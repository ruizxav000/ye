# Fantasy 16

A browser sampler in the spirit of the Akai MPC: a 4×4 grid of pads, a synthesized kit
(808 kick and boom, snare, clap, hats, keys, choir, brass, orchestra hit and more),
live loop recording quantized to 16th notes, note repeat, MPC-style swing, a step
sequencer with four sequences, and sample loading and chopping.

Open `index.html` in a browser. There's no build step and nothing to install.

## Keys

| Pads | Keys |
| --- | --- |
| 13–16 | `1` `2` `3` `4` |
| 9–12 | `Q` `W` `E` `R` |
| 5–8 | `A` `S` `D` `F` |
| 1–4 | `Z` `X` `C` `V` |

`Space` play/stop · `Enter` record · `N` note repeat · `M` metronome · `[` `]` tempo · `Ctrl/Cmd+Z` undo
